# Under Control · 竞彩足球预测 App

Android 原生应用（Kotlin + Jetpack Compose）：竞彩足球赛前预测、赔率方案计算与盈亏统计。

- **工程口径与交接手册**：见 [`docs/PROJECT_MEMORY.md`](docs/PROJECT_MEMORY.md)（红线、业务口径、架构、设计体系、构建与发布流程、已知遗留）
- **源码**：`jingcai-predict-android/`
- **签名产物**：`dist/jingcai-predict-v0.1.0-release.apk`
- **交互原型（历史）**：`jingcai-predict/index.html`

> 所有预测、赔率、赛果与统计均来自竞彩官方接口的真实数据；参数与结论可溯源、可复算。理性购彩。
